# OctoAcme Project Management Documentation

## Overview

OctoAcme uses a structured, customer-first project management approach that emphasizes iterative delivery, clear ownership, and data-informed decisions. Our process is designed to be lightweight, scalable, and focused on delivering value to customers and stakeholders.

This documentation serves as the central hub for all OctoAcme project management processes and serves as the entry point for team members looking to understand our approach and quickly access specific process guides.

## Core Principles

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Manager (PdM)
- **Data-informed**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

## Project Lifecycle

OctoAcme projects follow a five-phase lifecycle:

1. **[Initiation](./octoacme-project-initiation.md)** - Validate the business need, align stakeholders, and create a lightweight plan
2. **[Planning](./octoacme-project-planning.md)** - Break work into shippable increments and identify dependencies
3. **[Execution & Tracking](./octoacme-execution-and-tracking.md)** - Manage day-to-day execution and track progress
4. **[Release & Deployment](./octoacme-release-and-deployment.md)** - Standardize releases to production
5. **[Retrospective & Continuous Improvement](./octoacme-retrospective-and-continuous-improvement.md)** - Capture learnings and drive improvements

## Key Artifacts

Throughout the project lifecycle, teams create and maintain these key artifacts:

- **Project Charter / One-pager** - Problem statement, goals, success metrics, stakeholders, and timeline
- **Roadmap and Release Plan** - High-level delivery timeline and milestones
- **Sprint/Iteration Backlog** - Prioritized, estimated work items with acceptance criteria
- **Acceptance Criteria & Definition of Done** - Clear standards for what "done" means
- **Risk Register** - Tracked risks with impact, likelihood, owner, and mitigation plans
- **Retrospective Notes & Action Items** - Learnings and improvements from each sprint or milestone

## Communication Cadence

To maintain alignment and transparency, OctoAcme teams follow this communication rhythm:

- **Weekly PM + PdM sync** - Coordination between Project Manager and Product Manager
- **Twice-weekly standups** - Daily or twice-weekly delivery team synchronization (as agreed)
- **Monthly stakeholder updates** - High-level progress reports to leadership and stakeholders
- **Ad-hoc escalations** - Immediate communication for blockers, risks, and critical issues
